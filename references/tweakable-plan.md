# Tweakable plan

Use when implementation is ready but the plan mixes user decisions with routine mechanics.

1. Put the likely-to-change decisions first. Compare each default and alternative side by side, with cost and “choose this when” guidance.
2. Show the work sequence with a separate estimate or size for each stage. Identify stages that can be deferred.
3. Collapse routine setup, boilerplate, and unambiguous migrations under a detail section. Keep any material risk visible.
4. Offer a few copy-ready replies for plausible combinations of choices. Include a reply that stops before an unresolved decision.

Keep the plan short enough to review in one sitting. Estimates are rough and must not be presented as commitments.
