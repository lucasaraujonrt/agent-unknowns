# Change quiz

Use after implementation when a reviewer needs to understand the actual change and its operational implications.

1. Read the real diff and its tests. Report changed files and the relevant before/after behavior.
2. Explain 2–4 non-obvious behaviors with file references, plus dependencies such as migrations, flags, or release order.
3. Ask a few questions that check understanding of those behaviors. A wrong answer points back to the relevant explanation.
4. Build a reply stating what the reviewer understands and what remains open.

The quiz is a learning aid. Passing it never grants merge, deploy, spend, or publication approval. The host project's normal approval rules still apply.
