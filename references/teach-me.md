# Teach me

Use when the missing piece is a mental model or vocabulary for a concept, library, or protocol. For an incorrect assumption about current code, use `blindspot-pass` instead.

1. Read official documentation or primary sources. If the concept is already used in the host repository, anchor examples in that usage.
2. Explain the model in 3–4 short steps. Each step gets one concrete example.
3. Make a table of 5–8 terms: term, one-line meaning, and a prompt that uses it correctly.
4. Add a small interactive comparison only if changing a value makes the concept clearer. A static diagram is fine when interaction adds nothing.
5. End with 3–4 specific questions or prompts the user can select for the next step. The reply builder combines the selected prompts.

Label examples as illustrative. Never imply an external library or API currently behaves a certain way without checking its current documentation.
