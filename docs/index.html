THE IDEA

What does the skill change?

An agent can inspect the code, identify an unanswered assumption, and present a compact decision surface. The person’s selections become a reply for the agent to act on.

01

Route by phase

The skill chooses one of eleven techniques based on the work and its dominant uncertainty.

02

Ground in evidence

References tell the agent to inspect available code and distinguish fact from assumption.

03

Close the loop

Choice chips and a reply builder turn review into a concrete next action.
